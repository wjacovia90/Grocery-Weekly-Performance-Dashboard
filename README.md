# Grocery Store Weekly Performance Dashboard (Excel)

## 📌 Project Overview
This project analyzes weekly grocery store sales to identify performance trends, top‑selling departments, and opportunities for improvement. The final deliverable is an interactive Excel dashboard built using pivot tables, charts, and automated KPIs.

## 🛒 Business Scenario
A regional grocery chain wants to understand:
- Which departments drive the most revenue
- Weekly sales patterns
- Basket size trends
- Underperforming categories
- Forecasted sales for upcoming weeks

Your dashboard provides these insights in a clean, visual format.

## 🧰 Tools Used
- Microsoft Excel / Google Sheets  
- Pivot Tables  
- Pivot Charts  
- Conditional Formatting  
- Forecasting Tools  
- Data Cleaning Functions (XLOOKUP, TEXT, DATE, IF, etc.)

## 📊 Key Metrics
- Total Weekly Sales  
- Average Basket Size  
- YoY or WoW Growth  
- Top 5 Departments  
- Sales Forecast (Next 4 Weeks)
